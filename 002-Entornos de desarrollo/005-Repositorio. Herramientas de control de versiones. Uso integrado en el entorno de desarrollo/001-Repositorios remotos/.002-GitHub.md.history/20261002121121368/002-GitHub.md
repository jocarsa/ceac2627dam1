GitHub proviene de GIT

GIT es un proyecto creado por Linus Torvalds
Con el objetivo de:
1.-Versionear 
2.-Capacidad de trabajar en equipo

GIT es un software que cualquiera puede usar
De hecho en Linux viene preinstalado

1.-Servidor de proyectos
2.-Cliente que se conecta al servidor

GitHub: Es un proyecto basado en GIT (propiedad de Microsoft)
permite a los desarrolladores crear repo
sin tener que mantener un servidor
